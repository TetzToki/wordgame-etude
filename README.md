# Word Game Etude (wordgame-etude)

4×4マスの盤面を指でなぞって単語を探す、Boggle/Scramble系の単語探しゲームです。iPhone Safari上でPWAとして動作するように作られています。

## 遊び方
- 隣接するマス(斜めも含む8方向)を指でなぞって単語を作ります。
- 3文字以上の英単語が有効です。
- 制限時間は3分。スコアは単語の長さに応じて加算されます(3-4文字=1点, 5文字=2点, 6文字=3点, 7文字=5点, 8文字以上=11点)。
- タイムアップ後、盤面上に存在した全ての単語と、見逃した単語が確認できます。

## ローカルでの起動方法
```
python -m http.server 8000
```
起動後、`http://localhost:8000/index.html` にアクセスしてください。iPhoneで試す場合は同じWi-FiのLAN経由でPCのIPアドレスにアクセスするか、GitHub Pages等にデプロイしてください。

## 使用している辞書データ
単語判定には [ENABLE word list](https://github.com/dolph/dictionary) (enable1.txt, 172,819語)を利用しています。このリストは作者によりパブリックドメインとして公開されているデータです。
